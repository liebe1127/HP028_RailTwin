# dyn — 가상 모형 확장: 거리와 세로 가속도를 함께 만든다

`sim/railsim.py`(배용진)는 준정적 기하 모형이라 가속도를 만들지 않는다. 이 폴더는 같은 레일 모양에서 거리와 세로 가속도를 함께 만든다. 거리 AI와 가속도 AI를 합쳐 학습할 가상 데이터의 바탕이다. 2026-11-16 시작, 배준호.

## 파일

| 파일 | 내용 |
|---|---|
| `raildyn.py` | 바퀴 중심 궤적(`wheel_path`), 대차 동역학(`simulate_side`), 가속도 센서 읽기(`measure`), 거리 센서 읽기(`distance`) |
| `tests.py` | 자체 검사 12개. 닫힌 식, scipy 상태공간 계산, railsim 현측정과 비교 |
| `check_0928.py` | 9/28 실측 12회와 비교해 `../results/dyn_check_0928.md`, `.png` 를 만든다 |

```
pip install -r ../requirements.txt      # numpy, scipy, matplotlib 만 쓴다 (torch 불필요)
python3 tests.py
python3 check_0928.py
```

## 모형

1. **바퀴 궤적**: 반지름 R인 바퀴가 파이프 윗면을 구르다가 파이프 끝 모서리를 만나면 모서리를 중심으로 원호를 그린다. 3 mm 틈에서는 0.048 mm 내려앉고, 2 mm 단차는 모서리 9.5 mm 앞에서 닿아 세로 속도가 22 mm/s 뛴다(50 mm/s 주행).
2. **대차**: 한쪽 레일 위의 강체 보. 세로 위치와 앞뒤 기울기 두 자유도, 앞·뒤 바퀴를 스프링과 감쇠로 받친다. 좌·우는 railsim처럼 따로 계산한다.
3. **센서**: 칩 내부 저역 필터(2차 버터워스로 근사) → 표본 추출 → 잡음. 표본 속도와 필터를 바꿔 볼 수 있다.

## 9/28 실측과 비교한 결과 (`../results/dyn_check_0928.md`)

- **바퀴 위치**: 단차 주행에서 거리와 가속도가 변하는 센서 위치가 약 328, 864, 928, 1472 mm다. 센서에서 바퀴까지 약 270 mm에 해당한다. railsim 현측정 파형도 바퀴 간격 540 mm에서 실측과 가장 가깝다 (RMSE 좌 0.274 → 0.185, 우 0.267 → 0.187 mm). 가상 모형과 서버 판정(`pass_analysis.CHORD_HALF_MM`)은 500 mm를 쓴다.
- **충격 크기**: 50 Hz 표본에서 가상 단차 충격 0.60~0.66, 실측 0.46~0.83 m/s². 정상 이음부는 가상 0.39~0.40, 실측 0.36~0.50. 크기 자릿수는 맞는다.
- **맞출 수 없는 것**: 고유 진동수와 감쇠비. 15 Hz, 40 Hz, 120 Hz 대역에 비슷하게 맞는 값이 따로 있다. 50 Hz 표본으로는 충격 뒤 흔들림이 보이지 않기 때문이다.
- **실측의 사건별 차이**(뒷바퀴 600과 앞바퀴 1200이 크고 나머지 둘이 작음)는 이 모형으로 설명되지 않는다. 구동륜과 롤러의 차이, 가속도 센서 위치를 넣어야 하는데 실측값이 없다.
- 표본을 200 Hz(필터 94 Hz)로 올리면 세 후보의 단차 충격이 0.92 / 1.94 / 3.45 m/s²로 갈린다. 그 자료가 있어야 변수를 정할 수 있다.

## 하지 않은 것

- 좌·우를 묶은 3차원 운동(좌우 기울기, 비틀림), 바퀴 미끄러짐, 모터·롤러 자체 진동. 뒤의 것은 실측 정상 주행을 배경으로 더하는 방식으로 메울 계획이다.
- 바퀴가 뜨는 경우. `simulate_side` 의 `load_min` 이 0 이하면 그 구간은 맞지 않는다.
- 가상 데이터셋 생성과 학습. 새 측정 설정으로 실험한 뒤 변수를 다시 맞추고 나서 한다.
