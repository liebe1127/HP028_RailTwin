# 사례서 — 디지털 트윈 시뮬레이션으로 레일 결함 판정 시스템을 가상 검증한 사례 (2026-11-03)

PDF: 사례서_디지털트윈_가상검증_배용진.pdf (2장). 자소서·면접 답변의 원본.

## 1. 문제
센서 대차가 레일을 달리며 이음부 단차·수직 방향 변형·좌우 높이차를 찾고, 서버가 ISO 12488-1 기준으로 정상·주의·위험을 판정해 Unity 트윈에 보여 주는 시스템. 실물 실험 24회(결함 2 mm, 네 구성)로 논문 검증은 끝났지만, 실험이 덮지 못한 영역(작은 결함, 다른 위치·모양, 레일 설치 변형, 다른 속도)에서도 판정이 맞는지는 알 수 없었다.

## 2. 한 일
- 모델: 실물 치수로 센서 값을 계산하는 준정적 기구학 모델(파이썬). 손 계산 21건 대조.
- 교정·타당성: 정상 6회로 설치 높이·레일 굴곡·잡음(좌 0.135/우 0.089)을 정하고 결함 18회를 예측 → RMSE 0.14~0.36, 단차 1.95/1.74(논문 1.84), 우 레일 1200 단차 0.70(논문 약 0.7).
- 가상 데이터: 종류·크기·위치·속도·엔코더 미끄러짐·레일 다시 놓임을 바꾼 2,000 + 1,800회.
- 가상→실물: 가상으로만 학습한 판별기 실측 18회 중 종류 17/18. 가상 78 % 회귀가 실물 13/18 → "평가는 실측으로만".
- 가상 시운전: 서버 판정 코드 그대로에 1,800회 재생 → 문제 4건 → 수정안 모듈 → 같은 1,800회로 전/후 재검증.

## 3. 문제와 수정 결과
| 문제 | 수정 | 전 | 후 |
|---|---|---|---|
| 분류 문턱 = 허용 한계 → 주의 단계 불가 | 문턱 분리, 3회 평균 판별 | 주의→주의 9 % | 44 % |
| 템플릿 두 모양 고정 → 다른 모양 크기 0.26~0.55배, 위치 고정 | 끝 높이 4개 기본형, 좌우 따로 | 0.26~0.55 | 1.00~1.04, 위치 81 % |
| 레일 모양 0.1 mm 변화에 정상 47~90 % 오경보 | E 문턱 2.5, 드리프트 지표 | 오경보 67 % | 35 % |
| 감속·정지가 분석과 미연결, 정지 0회, 결함 뒤 +191 mm | 분석 결과 연결, 앞 두 구간, 좌표 변환 | 정지 0/39, 결함 앞 36 % | 27/39, −299 mm, 81 % |
위험 결함→위험 53 → 81 %, 종류 정답 35 → 66 %. 실측 24회는 수정 후에도 단차·처짐 12/12 위험.

## 4. 배운 점
- 시뮬레이션은 실측을 없애는 게 아니라 어떤 실측이 필요한지 알려 준다 (좌우 높이차 2 mm < ISO 주의선 2.5 → 4~6 mm 재실험 설계).
- 실물 시험은 한 점, 시뮬레이션은 그 주변. 24회에서 완벽한 로직이 그 점 밖에서 네 곳 무너짐.
- 가상 안 성능 ≠ 실물 성능. 평가는 실측으로, 가상은 학습과 범위 확장에.
- 버릴 것과 남길 것을 숫자로 정한다 (바퀴 반지름 0.05 < 잡음 0.135 → 버림, 다시 놓임 0.3 ≈ 신호 0.4 → 넣음).

## 5. 역할과 도구
하드웨어 설계·제작과 실험, 논문 1저자, 시뮬레이션 모델·검증·가상 데이터·가상 시운전·수정안 전부. 서버·Unity는 팀원. Python(numpy·scipy·scikit-learn), 실측 24회, ISO 12488-1.
