# 가상 레일·대차 모델 1차 결과 (2026-10-28)

## 목적
실물 시험 장치를 센서 값 수준에서 파이썬으로 옮겨, (1) 실측과 얼마나 맞는지 숫자로 확인하고, (2) 결함 크기를 바꿔가며 가상 주행을 만들어 AI 학습 데이터와 제어 가상 검증에 쓰기 위함. Unity 물리 엔진은 쓰지 않고, 결과를 Unity 트윈에 흘려 넣는 구조.

## 모델
- 레일: 600 mm 각파이프 3개, 받침 0/600/1200/1800 mm. 파이프는 강체, 양 끝 받침 높이를 직선으로 잇는다. 이음부 3 mm 틈.
- 받침: N 23, D 21, S 한쪽 23/다른 쪽 21. 논문 표 2 표기(S>, <S) 그대로 입력.
- 대차: 바퀴 간격 500 mm, 변위센서는 한가운데(현측정).
- 센서 값 = 설치 높이 + (앞뒤 바퀴 접점을 잇는 현의 높이 − 센서 아래 레일 높이) + 틈 위 스파이크.
- 실측 CSV 정렬: 틈 스파이크 두 개가 600, 1200에 오도록 엔코더 위치를 선형 보정(논문 3.1 방법). 좌·우 따로.

## 9/28 1회차 실측과 비교
- 네 구성 중 "4 좌우 높이차"가 좌·우 모두 오차 최소. 이 회차는 구성 4로 판단.
- 좌: 설치 높이 6.28 mm, RMSE 0.161 mm, 평균 절대 오차 0.136 mm. 600·1200 kink의 삼각 봉우리(모델 +0.29/+0.34, 실측 +0.13/+0.62) 추세 일치.
- 우: 설치 높이 6.48 mm, RMSE 0.152 mm, 평균 절대 오차 0.111 mm. 1200 이음부에서 3번 파이프 왼쪽 끝이 +0.98 mm 높아야 실측이 설명됨. 앞뒤 단차 신호 실측 +0.94 / 모델 +0.98 mm. 논문 3.2의 "우 레일 1200 약 0.7 mm 단차"와 같은 현상.
- 오차 계산 범위 x 350~1500 mm, 이음부 ±20 mm 제외. 남은 ±0.3 mm 흔들림은 파이프 자체 휨 + 센서 잡음으로 보이며, 정상 구성 6회 평균(기준선)이 있어야 분리 가능.

## 아직 없는 것 / 다음 단계
1. 정상 구성 회차 CSV로 기준선 만들기 → 파이프 휨·잡음 분리.
2. MPU6050 피치·롤·가속도 모델 추가.
3. 시나리오 생성기 본편(결함 종류·크기·위치·속도·겹침, 정답 라벨 포함, 수백~수천 회).
4. 정상/감속/정지 판정 로직을 가상 주행에 돌려 가상 시운전, 실물 기록과 비교.
5. 가상 주행을 Unity 트윈에 재생.
