# 과적합 검사 (2026-11-03)

## 1. 판정 엔진 수정안이 '본 데이터'에만 맞춘 것인가
수정안은 가상 1,800회(seed 2)의 실패를 보고 설계했고 같은 1,800회로 점수를 냈다 → 시험지를 보고 공부한 셈일 수 있어 새 seed(9, 240배치×3회)로 다시 잼.
| 항목 | seed 2 (설계 때 본 것) 전→후 | seed 9 (처음 보는 것) 전→후 |
|---|---|---|
| 종류 정답(1회) | 35→66 % | 28→59 % |
| 위험→위험 | 53→81 % | 49→77 % |
| 주의→주의 | 9→44 % | 23→44 % |
| 정상 오경보(1회) | 67→35 % | 69→44 % |
| 단차 크기 비율 | 0.50→1.15 | 0.52→1.13 |
→ 개선 폭이 그대로 유지. 수정안의 문턱(0.5, 2.5)과 앞 구간 수(2)는 ISO 규칙과 구조에서 정한 값이지 점수를 보고 맞춘 값이 아님.

## 2. 가상→실물 판별기의 누수(leakage)
가상 학습 데이터의 잡음은 실측 정상 6회의 잔차를 재사용하고, 그 6회가 실측 평가에도 들어간다 → 정상 회차 성적이 부풀 수 있음.
검사: 잡음 은행·기준선을 정상 31~33으로만 만들어 가상 900회를 새로 생성·학습하고, 34~36은 '본 적 없는' 실측으로 평가.
- 회귀 B: 제외(34~36) 정상 3/3, 포함(31~33) 2/3(센서 이상 회차), 결함 12회 종류 12/12·단계 9/12 — 6회 전부 썼을 때와 같은 수준
- 규칙 A: 제외 3/3, 결함 단계 12/12
→ 정상 회차 성적이 잔차 재사용 때문이 아님.

## 3. 남는 한계 (검사로 못 없애는 것)
- 모델 교정은 정상 6회만 썼고 결함 18회는 예측에만 썼으므로 거기엔 과적합이 없다. 다만 실측 24회를 과정 내내 여러 번 봤다(센서 이상 구간 제외 결정 등). 이건 새 실측(좌우 높이차 4~6 mm 실험)이 와야 최종 확인된다.
- 수정안 v2의 '주의→주의 44 %'와 '모양 변화 0.15 이상에서 오경보 51 %'는 과적합이 아니라 신호 크기와 설치 편차의 물리적 한계.
