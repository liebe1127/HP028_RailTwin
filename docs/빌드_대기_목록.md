# 빌드·배포 대기 목록

코드는 저장소에 들어갔지만 아직 서버 설정·펌웨어 업로드·시험이 남은 작업이다. 위에서부터 순서대로 처리하고, 끝난 항목은 지운다.

결정(2026-11-07, AI 개발 PM 배준호):

1. 판정 엔진은 **v1 → v2 → v2 + AI** 순서로 단계적으로 켠다
2. "주행 분석 결과로 감속·정지, 앞 2구간 미리 보기"는 설정(`RAIL_MOTION_FROM_PASS`)으로 분리한다. 비워 두면 v2일 때만 켜진다
3. **펌웨어 동기화를 먼저** 올리고, AI는 그 뒤 새 정상 주행으로 재적응한 다음에 켠다
4. AI 재적응은 배준호 맥북 M5 Pro에서 한다

## 2단계: 펌웨어 좌·우 동기화 (0.6.8-draft)

인수인계서(2026-09-24)는 같은 PWM에서 좌 모터가 약 13% 빨라 `syncDrive()`를 유지하라고 했지만, 실물용 0.6.7-draft에는 동기화가 없었다. 9/28 실측의 좌·우 엔코더 차(최대 29%)의 원인으로 본다. 0.6.8-draft는 간 거리 차(mm) × `SYNC_KP`(2.0)만큼 빠른 쪽 듀티를 빼고 느린 쪽에 더한다. **클라우드에 arduino-cli가 없어 컴파일하지 못했다.**

- [ ] 컴파일: `arduino-cli compile --fqbn esp32:esp32:esp32s3:CDCOnBoot=cdc firmware/esp32_s3_rail_node`
- [ ] 업로드: `arduino-cli board list`로 포트 확인 → `arduino-cli upload -p <포트> --fqbn esp32:esp32:esp32s3:CDCOnBoot=cdc firmware/esp32_s3_rail_node`
- [ ] 시리얼 시작 줄이 `0.6.8-draft`인지
- [ ] `g`(평속)로 달리며 `r`: 좌·우 위치 차가 수 mm 안인지, 줄 끝 `동기화` 값이 작게 + 쪽인지. 흔들리면 `SYNC_KP` 1.0, 벌어지면 3.0
- [ ] BOOT 25초 주행 뒤 줄자 이동 거리와 좌 엔코더 거리 비교. 10% 가까이 차이 나면 바퀴 지름을 재서 `MM_PER_COUNT` 수정
- [ ] 줄자 실측: 엔코더 0 출발 자세에서 레일 왼쪽 끝 → LR18 센서 중심 거리. `RAIL_ENCODER_ZERO_MM` = 잰 값 − 250 (지금 40은 9/28 역산값)
- [ ] 정상 레일 3회 이상 주행 → 대시보드 기준선 모드로 **기준선 재등록** (v1)
- [ ] 정상 주행 CSV(`/runs`)를 **5회 이상** 내려받아 둔다 → 4단계 AI 재적응에 쓴다
- [ ] 실험 절차와 재생 분석: `docs/실험_체크리스트_2mm단차.md`, `python scripts/experiment_report.py <실험 폴더>`

## 3단계: 판정 규칙 v2 켜기 (AI 끔)

v2는 판정 규칙 자체를 바꾼다(`docs/ai-judge.md`). 결함 "있음"을 한계선의 절반(0.5 mm)부터 보아 주의 단계가 생기고, 레일 끝 높이 4개로 크기·위치를 맞추며, 기준선은 중앙값이다. 감속·정지도 주행 분석 결과로 앞 2구간을 미리 보게 된다.

알고 켤 것: 9/28 실측 재생에서 v2(AI 끔)는 좌우 높이차 구성 6회를 "우측 1200 단차 0.7 mm 주의"로 대표 표시한다(판별 12/18). 실제로 있던 0.7 mm 단차를 따로 잡은 것이고 좌우 높이차도 목록에 같이 나온다. AI를 켜면 좌우 높이차가 대표로 돌아온다. 레일이 0.15 mm 이상 다시 놓이면 정상인데 주의가 뜰 수 있다(가상 51%) → "기준선 점검" 줄이 뜨면 기준선 재등록.

- [ ] 서버 `.env`: `RAIL_JUDGE=v2` → 재시작 → `judge.version`이 `v2`, `motion_from_pass`가 `true`인지
- [ ] v2 기준선은 v1 파일을 그대로 읽는다. 다만 중앙값 기준선을 쓰려면 정상 3회 이상 **다시 등록**
- [ ] 결함 앞에서 감속·정지 신호가 나오는지 주행으로 확인

## 확인 필요

- 결함 크기 실측은 2 mm 한 가지뿐이다. 0.5~1.5 mm 결함 실험을 하면 주의 단계와 AI 크기 눈금을 처음으로 실측 확인할 수 있다
- 좌우 높이차는 AI가 재지 않는다(4~6 mm 실험 뒤 추가 예정, 배용진)
- 레일 구조(파이프 길이·개수, 이음부 위치, 바퀴 간격, 센서 위치)가 바뀌면 재적응이 아니라 가상 모형부터 다시 교정하고 재학습해야 한다
